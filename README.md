# Hortiolinda — Instalador para Windows

Repositório público para distribuição do instalador do Hortiolinda.

## Versão

- **Versão:** 1.0.1 (Sincronização)
- **Arquivo esperado:** `Hortiolinda-1.0.1-Sincronizacao-Setup.exe`
- **Plataforma:** Windows
- **Download:** consulte a seção [Releases](../../releases). O instalador ainda precisa ser anexado a uma release.

## Instalação

1. Acesse a seção **Releases** deste repositório.
2. Baixe o arquivo `Hortiolinda-1.0.1-Sincronizacao-Setup.exe` quando publicado.
3. Verifique o arquivo antes de executá-lo.
4. Execute o instalador em um computador Windows compatível.

> **Atenção:** antes de publicar o executável, revise se ele não contém informações confidenciais ou credenciais embutidas. O repositório é público.
